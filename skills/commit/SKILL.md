Commit the finished work to the current branch: one logical change per commit, conventional
commits format, and follow the repo's documented commit rules where it has them. Never push
and never force-push — publishing belongs to the flow's PR step.

## Ported from the interactive original

The interactive original staged files and confirmed the message with the user; an AFK
session stages its own changes and commits without confirmation.
